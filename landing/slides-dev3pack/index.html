Appendix · The metering engine

Off the chain, the books are
exact to the micro-unit.

A self-hosted gateway (released as v0.1.4) meters every request and keeps the double-entry ledger.
Settlement reads that ledger: no request ever routes on-chain.
Per-member keys, quotas and an append-only audit log come with it.
Appendix · The Web2 credit resellers

Operator-run gateways:
your balance is a row in their database.

Open-source gateways such as New API (GitHub) let anyone run a credit-resale site: users top up a balance with the operator.
The operator holds the upstream keys and the money; the balance is mutable by the operator and cannot be verified from outside.
If the site closes, the prepaid balance is gone. Only the operator trades: users with surplus still cannot sell.
New API's own README asks operators to settle payment, licensing and upstream-authorization duties before reselling in public.

Appendix · Design decision

We evaluated x402.
Prepaid escrow stays.

x402 upto: authorize a max, settle the actual — built for one paid call.
A prepaid balance needs what it skips: funds inside our escrow,
zero confirmations per request, streaming. Escrow stays; x402 may return as a second door.
